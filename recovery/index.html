Restore data

Browse a restic snapshot and download files. Everything happens in this browser; nothing is uploaded.

    Restoring the whole library needs a browser that can write into a folder: Chrome or Edge on a Mac. Safari can still download single files. Nothing is uploaded, and files already in the folder are skipped, so a stopped restore can be run again.

    Data restore is client-side. No password, key, or file is sent to a server.
