Family Access

This page is only for people the owner has chosen. If you are not one of them, close it.

Before you start

  • Use a device you trust, not a shared or public computer.
  • Keep the drive and the sealed letter in separate places.
  • The PWA password is not your Bitwarden password.

Unlock the data keys

Enter the PWA password from the sealed letter or the drive. It is never stored or sent anywhere.

Restore data

Browse a restic snapshot and download files. Everything happens in this browser; nothing is uploaded.

    Restoring the whole library needs a browser that can write into a folder: Chrome or Edge on a Mac. Safari can still download single files. Nothing is uploaded, and files already in the folder are skipped, so a stopped restore can be run again.

    Read Bitwarden items (optional)

    If you have a password-protected Bitwarden JSON export, load it here to show the credentials next to these instructions. It is decrypted in this browser and never uploaded.

    Data restore is client-side. No password, key, or file is sent to a server.
